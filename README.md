# MovieCenter 电影中心

自托管的本地电影媒体库：扫描硬盘里的影片自动入库，从 TMDB 抓取海报与资料，豆瓣评分与 Top 250 自动匹配，内置在线播放（服务器转码）、本地播放、评分、观影日记、片单、盲盒推荐与统计报告。数据完全保存在本地。

## 功能一览

### 影库管理
- **自动入库**：扫描指定目录（各盘根目录的 `电影` 文件夹可自动识别），按文件夹名解析标题与年份；支持 21 种视频格式、5 层目录深度
- **增量扫描**：目录签名缓存，未变化的目录直接跳过，大库启动秒级完成；也可随时强制完整扫描
- **文件夹监听**：服务运行期间监控扫描目录，新片放入静默 30 秒后自动入库（可开关）
- **元数据刮削**：TMDB 海报 / 简介 / 演职员 / 合集（单片刮削 + 批量补全，仅高置信度自动匹配，支持手动搜索候选 / IMDb ID 指定）；直连不通时支持 HTTP 代理
- **豆瓣集成**：Top 250 榜单抓取与库内自动对号；评分批量同步（自带限流退避）；单片自动同步 + 手动搜索/贴链接绑定豆瓣条目
- **豆瓣片单同步**：填豆瓣 UID，一键同步「想看 / 已看」片单；已看记录自动对号入库影片、回填你的豆瓣评分
- **画质识别**：文件名识别 + ffprobe 深度识别真实分辨率；单片可随时重识别
- **未同步角标**：缺海报 / 简介的影片在库页标红「未同步」，可一键筛选、批量补全

### 播放
- **在线播放（服务器转码）**：浏览器 / 手机直接看。H.264/AAC 直连原画；HEVC / 10-bit / HDR 自动转码 HLS
  - 四级硬件自动降级：NVIDIA 硬编 → NVIDIA 硬解 → Intel 核显 QSV → CPU 软转码
  - HDR10 / HLG → SDR 色调映射；PGS / 外挂字幕烧录（中文轨优先）
  - 画质可选 1080p（流畅）或 4K（保画质），宽高比保真、不放大
  - 并发转码上限 5 路；实时转码进度、会话监控
- **本地播放**：一键唤起 PotPlayer（自动检测，路径可配）
- **续播与统计联动**：在线播放每 10 秒记录进度；看够 90% 自动标已看 + 写观影日记

### 记录与发现
- **看片管理**：已看 / 收藏 / 我的评分（含评分历史与短评）/ 观看次数
- **观影日记**：每次播放（本地 / 在线）或手动记录自动生成时间线；可补写感想、按年份回顾
- **年度报告**：某年的观影次数、月度曲线、类型分布、平均分、年度最爱与五星片单
- **自定义片单**：任意主题收藏夹，支持排序、一键随机抽片
- **智能推荐**：详情页「喜欢这部的人还看了」（共同导演 / 主演 / 类型加权）；盲盒支持按口味加权随机
- **盲盒放映**：跑马灯拆盒动画，按豆瓣 / TMDB 评分或个人口味加权抽取
- **想看清单**：豆瓣片单同步或粘贴文本导入，自动匹配库内已有影片；新片入库后自动对号
- **全局搜索**：顶栏一处搜电影 / 人物 / 标签 / 片单 / 想看
- **统计面板**：库容量、评分分布、类型 / 年代 / 导演 / 演员分布、观影排行
- **NFO 导出**：单片或批量把刮削结果写回影片文件夹（Kodi / Emby / Jellyfin 兼容）

### 系统与运维
- **性能监控页**：CPU / 内存 / 服务进程 / 系统运行时间实时卡片；转码会话明细（后端类型 / 画质 / 进度条）；自动入库监听状态
- **PWA**：手机浏览器「添加到主屏幕」，类原生 App 全屏体验
- **移动端适配**：全站 700px 断点自适应，手机访问局域网页面
- **其它**：每周自动备份数据库、开机自启、局域网访问、重复影片检测、中文拼音搜索、start.bat 代码指纹自动重启

## 快速开始（Windows）

1. 安装 [Node.js 20+](https://nodejs.org)（含 npm）
2. 双击 `start.bat`
   - 首次运行会自动安装依赖并构建前端（约 1 分钟，仅一次）
   - 之后自动启动服务并打开浏览器 `http://localhost:9527`
   - 代码有更新时再次双击会自动检测并重启换新
3. （推荐）安装 FFmpeg（如 `winget install Gyan.FFmpeg`）：
   - 画质识别读取视频真实分辨率
   - 在线播放转码（HEVC / 4K / HDR 片源必需）

局域网设备（手机 / 平板 / 电视）直接访问启动窗口里显示的 `http://<电脑IP>:9527`。

## 扫描目录约定

- 每个扫描目录下，**一个文件夹 = 一部电影**，文件夹名建议 `片名 (年份)`，例如 `星际穿越 (2014)`
- 文件夹内所有视频会计入该片，体积最大的作为主文件播放
- 支持多目录（多块硬盘 / NAS 映射盘），在「设置 → 影库」中管理

## 元数据配置（可选但推荐）

1. 打开「设置 → TMDB」
2. 填写 TMDB API Key（[免费注册获取](https://www.themoviedb.org/settings/api)，v3 密钥或 v4 Token 均可）
3. TMDB 直连不通时填写代理地址（如 `http://127.0.0.1:7897`）
4. 点「测试连接」验证，然后「自动补全缺失信息」

豆瓣 Top 250 与评分同步无需配置，首次打开页面自动抓取。想同步个人片单，在「设置 → 豆瓣」填 UID 即可。

## 播放说明

- **能直连的片**（H.264 编码）直接原画播放，服务器零负担
- **需要转码的片**（HEVC / 10-bit / HDR）服务器实时转 HLS；无独立显卡时 Intel 核显 QSV 可扛数路 1080p，装 NVIDIA 显卡后自动用 NVENC
- 手机系统播放器也可直接播放转码流（m3u8 链接），总时长、拖动条均为真实片长
- 转码画质在播放前可选 1080p / 4K（4K 需较高 Wi-Fi 带宽，电视 / 有线设备无压力）

## 数据与备份

- 所有数据保存在 `server/data/`（SQLite 数据库 + 封面缓存），删除即清空
- 服务每周自动备份数据库到 `server/data/backup/`，也可在设置里手动备份
- 开机自启：设置 → 系统（写入当前用户的启动目录 VBS）

## 开发

```bash
# 服务端（端口 9527，前端构建产物由 Express 托管）
cd server && npm install && npm run dev

# 前端（开发热更新，另起端口）
cd web && npm install && npm run dev

# 前端构建（部署用）
cd web && npm run build
```

环境变量（均可省略）：`PORT`（默认 9527）、`MC_DATA_DIR`（数据目录）、`MC_FFPROBE`（自定义 ffprobe 路径）、`MC_TMDB_BASE` / `MC_TMDB_IMG_BASE`（TMDB 镜像）。

测试隔离：`PORT=9528 MC_DATA_DIR=<临时目录> node server/src/index.js`，不碰生产库。
